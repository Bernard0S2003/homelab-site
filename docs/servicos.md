# 📦 Serviços Self-Hosted

Lista das principais aplicações em execução no homelab:

---

### 🛡️ Rede & Segurança
- **DNS / AdBlock:** AdGuard Home ou Pi-hole
- **Reverse Proxy:** Nginx Proxy Manager (gestão de certificados SSL)
- **VPN:** Tailscale / WireGuard

### 📊 Gestão & Monitorização
- **Proxmox VE:** Gestão de máquinas virtuais e containers LXC
- **Portainer / Dockge:** Gestão dos contentores Docker
- **Uptime Kuma:** Monitorização de disponibilidade dos serviços

### 📁 Armazenamento & Utilidades
- **Nextcloud / Immich:** Partilha de ficheiros e galeria de fotos
- **Vaultwarden:** Gestão de palavras-passe
- **Homepage:** Dashboard de acesso rápido aos serviços
